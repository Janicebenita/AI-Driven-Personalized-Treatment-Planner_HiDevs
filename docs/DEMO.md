# CareWeave demo — 3 minutes

**Opening, 0:00–0:20.** “A treatment plan must account for the person, show its evidence and make uncertainty visible. CareWeave is a clinician-review prototype for adult type 2 diabetes. All cases in this demo are synthetic.”

**Personalization, 0:20–1:00.** Start with Maya. Point to eGFR 42, confirmed CKD, poor SLCO1B1 function and simvastatin. Show the kidney-specific rationale, affordability and lifestyle context. Open Safety signals to show the gene–drug alert and linked CPIC evidence. Explain that the phenotype is entered from a verified result, never inferred.

**Counterfactual, 1:00–1:40.** Change eGFR to 24. The previous report disappears immediately. Build again: the routine metformin pathway changes and a prompt prescriber-review warning appears. Open Follow-up to show the renal and volume checks. Explain that this is a discussion pathway, not a dosing calculator.

**Trust, 1:40–2:10.** Open Evidence and Rationale. Show source IDs, guideline sections, retrieval cosine values and missing information. Explain that similarity measures relevance, not clinical certainty, and that the corpus is deliberately small.

**Safety, 2:10–2:35.** Check Acute symptoms and rebuild. Show zero routine options and an urgent assessment signal. Explain that independent rules cannot be overridden by AI.

**GenAI and close, 2:35–3:00.** If configured, return to Maya, opt into the AI briefing and show the source-constrained synthesis and uncertainty. If unconfigured, say clearly: “Live AI is not configured here; you are seeing the transparent rules-only engine. The server integration and its contract tests are included.” Close with the clinician-review boundary and export functionality.

Do not claim clinical accuracy, improved patient outcomes, a leaderboard position, live model testing or challenge submission unless independently verified.
